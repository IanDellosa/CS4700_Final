# The Adventures of Sticky and Petunia

Clone github repo and build on unity editor version 6 or higher to run.

A WIP puzzle game for CS 4700

## Features
- Lobby and Relay systems to connect to multiplayer
- Item pickup and Inventory System
- Crafting System
